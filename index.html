三分钟上手

这台工具把「弹」到「发出去」之间的所有环节串在了一个页面里，数据不离开本机。

基本流程

  1. 连接　点右上角「连接钢琴」，在弹窗里选 Dight Piano MIDI ××××。琴的蓝牙要处于可被发现状态——厂商 App 里能搜到、但不要点连接，同一时刻只允许一个连接。
  2. 录音　点「开始录音」，默认走四拍预备。想跟节拍器就勾上右侧开关，拍号可以设 4/4、3/4、2/4、6/8。
  3. 出谱　五线谱和简谱会边弹边长。BPM 是自动估的，不准就拖滑块调，再点「重新排版」。
  4. 导出　MIDI 是可编辑的演奏数据，换音源能重新发声；WAV / MP3 是当前页面合成好的成品。
  5. 剪　到「音频剪辑」点「载入录音」，或直接把 mp3 / wav 拖进窗口，然后分割、拖动、裁剪。

剪辑快捷键（先点一下波形）

空格播放 / 停止
Ctrl+B在播放头处分割片段
Delete删除选区
Ctrl+Z / Ctrl+Shift+Z撤销 / 重做（30 步）
Ctrl+C / Ctrl+V复制选区 / 粘贴到播放头
← →播放头移动 0.1 秒
Alt + 拖动关闭 0.05 秒吸附
Shift + 拖动在片段上强制框选时间段

关于踏板：不少入门琴只把踏板信号送给内部音源，不往蓝牙广播。右侧的「踏板监视器」会实时显示收到的 CC 事件；如果踩下去一直是 0，那就是硬件不发，只能靠「模拟踏板」补延音。
